# Katalog /lib

Ten katalog służy jako centralne miejsce na wszystkie logiki i narzędzia, które nie są komponentami interfejsu użytkownika (UI).
Gdy w przyszłości dema staną się bardziej dynamiczne, tutaj powinny trafiać:
1. Skrypty łączące się z Supabase (pobieranie danych o produktach per slug).
2. Funkcje formatujące waluty, daty lub obliczające rabaty (dla e-commerce).
3. Narzędzia pomocnicze (utils) takie jak łączenie klas CSS.
